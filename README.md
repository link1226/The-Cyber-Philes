**Getting Started**
To play the Cyber Philes, follow these steps:

1. Clone the Repository: Clone this repository to your local machine using git clone “git clone https://github.com/link1226/The-Cyber-Philes.git”
2. Set Up Unity: Ensure you have Unity 6.2 (6000.2.2f1) installed
3. Run the Game: Build and run the game within your preferred VR environment, you can use a VR headset that you own or use the simulated VR controls within the game.
